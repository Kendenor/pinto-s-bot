## 🔐 Step 1 — Link WhatsApp & Get Session

> ⚡ You can link your phone in **seconds** without downloading anything or scanning a QR code using our web pairing engine.

1. Open your Pinto Web Portal: `/pair`
2. Enter your WhatsApp number in international format (e.g. `23274960906`)
3. Click **Generate Code**
4. On your phone: **WhatsApp → Settings → Linked Devices → Link a Device → Link with phone number instead**
5. Enter the 8-digit code shown on screen.
6. Once connected, your Session ID is sent directly to your WhatsApp DM!

### 1. Deploy Bot to Koyeb (Backend)
1. Fork or import this repo into your GitHub.
2. Go to [Koyeb.com](https://app.koyeb.com) and create a **Web Service**.
3. Choose GitHub → `WhatsAppBot`.
4. Set Build command: `npm install` and Run command: `node src/index.js`.
5. Expose Port: `5001`.
6. Add environment variable `PORT = 5001`.
7. Click **Deploy** and copy your Koyeb domain (e.g., `https://pinto-bot.koyeb.app`).
